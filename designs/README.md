# Designs

Every file in these folders appears on the website automatically.

- `common-room/` shows under **Student common room**
- `music-studio/` shows under **Music practice studio**
- Any new folder (for example `science-lab/`) becomes a new space with that name.

## What you can add

- **3D models:** `.glb` files (or a single-file `.gltf`). These become rooms you can walk through.
- **Images:** `.png`, `.jpg` or `.webp`. These become design boards.

## Naming

- The file name is the design's title: `Quiet study corner.glb`.
- If the model was made in centimetres, millimetres, inches or feet, add the unit in brackets: `Quiet study corner (cm).glb`. Without it the model is read as metres.
- For notes, add a text file with the same name: `Quiet study corner.txt`.

## How to upload

Open the folder on GitHub, choose **Add file → Upload files**, drop the files in and press **Commit changes**.
